# Habitat School 9P — My First Website

This was my first website, created as a 9P project at Habitat School Al Jurf in Ajman, UAE. It introduces the Java, Python, and PHP programming languages.

The project was also part of our school's contribution to the Guinness World Records title **“Most Users in a Web Development Video Hangout.”** Habitat School Al Jurf achieved the record with 2,803 participants on 10 January 2022.

## Run locally

Open `index.html` in a web browser. The navigation links open the home, content, and about pages.
